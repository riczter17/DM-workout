# Project context
Couples Workout Tracker. Single-file HTML app deployed to GitHub Pages. No build step. Edits are made directly to the .html file.

# Standing rules
- Before making any code edit, summarise the full list of planned changes and wait for explicit confirmation. Do not edit files until I say "go" or equivalent.
- For every new version, bump the version number in the HTML and generate a changelog entry (version number, date, list of changes). The changelog lives in CHANGELOG.md at the project root. Create CHANGELOG.md if it does not exist.
- Use UK English in all comments and user-facing strings.
- Never use em dashes.

# Deployment
Push to main; GitHub Pages auto-deploys.
